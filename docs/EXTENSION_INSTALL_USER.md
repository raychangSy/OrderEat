# OrderEat 點餐小工具：安裝教學

OrderEat 是裝在 Chrome 瀏覽器上的點餐小工具，裝好後點一下瀏覽器右上角的圖示就能點餐。

> 也可以用 Edge、Brave 等瀏覽器，步驟一樣。

## 步驟 1：解壓縮

1. 下載收到的 `extension.zip`。
2. 對著檔案按兩下（或按右鍵 →「解壓縮」），會得到一個 `extension` 資料夾。
3. 把這個資料夾移到**不會被刪掉的地方**，例如「文件」資料夾。

> ⚠️ 安裝後這個資料夾**不能刪除或移動**，否則小工具會失效。不要放在「下載」或桌面這種常清理的地方。

## 步驟 2：打開擴充功能頁面

在 Chrome 網址列輸入以下網址，按 Enter：

```
chrome://extensions
```

（Edge 請輸入 `edge://extensions`）

## 步驟 3：開啟「開發人員模式」

在頁面**右上角**找到「開發人員模式」開關，把它打開。

打開後，左上方會出現幾個新按鈕。

## 步驟 4：載入小工具

1. 點左上角的 **「載入未封裝項目」**。
2. 選擇步驟 1 的 `extension` 資料夾，按「選取」。
3. 清單中出現 **「OrderEat 個人點餐」** 就安裝好了 🎉

> 如果跳出「找不到資訊清單檔案」，代表選錯資料夾。請打開 `extension` 資料夾看看，要選的是**裡面直接有 `manifest.json` 檔案**的那一層。

## 步驟 5：把圖示固定在工具列

1. 點瀏覽器右上角的 **拼圖圖示 🧩**。
2. 找到「OrderEat 個人點餐」，按旁邊的 **圖釘 📌**。

之後 OrderEat 圖示就會一直顯示在右上角。

## 開始點餐

1. 點右上角的 OrderEat 圖示。
2. 選擇要點的團。
3. 選自己的名字（下次會自動記住）。
4. 選餐點，按送出。

> 看不到別人剛點的單？按右上角的 **↻** 重新整理。

## 有新版本時

1. 用新的檔案取代原本的 `extension` 資料夾（位置不變）。
2. 打開 `chrome://extensions`，在 OrderEat 上按 **重新載入 ↻**。

## 常見問題

**Q：每次打開 Chrome 都跳出「停用開發人員模式擴充功能」的提示？**
A：正常現象，按右邊的 ✕ 關掉就好，**不要按「停用」**。

**Q：小工具突然不見或不能用了？**
A：可能是 `extension` 資料夾被刪掉或移動了，請重新從步驟 1 安裝。

**Q：看不到要點的團？**
A：先按 ↻ 重新整理。還是沒有的話，請聯絡開團的人。

**Q：其他問題**
A：請截圖聯絡管理員。
