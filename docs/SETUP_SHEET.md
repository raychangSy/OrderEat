# Google Sheet 後端建立教學

照順序做，每步都有「✅ 確認」，看到才往下一步。全程約 15 分鐘，只需要電腦瀏覽器和 Google 帳號。

---

## 步驟 1：建立試算表

1. 瀏覽器開 <https://sheets.new>（會直接建一份新試算表）
2. 左上角「未命名的試算表」改名為 **OrderEat**

✅ 確認：看到空白試算表，標題是 OrderEat

---

## 步驟 2：貼上 Apps Script 程式

1. 上方選單 **擴充功能 → Apps Script**，會開新分頁
2. 左上「未命名的專案」改名為 **OrderEat**
3. 左側檔案 `程式碼.gs`（或 `Code.gs`）裡預設有 `function myFunction() {}`，**全部刪掉**
4. 打開本專案的 [`apps-script/Code.gs`](../apps-script/Code.gs)，**全選複製**，貼進去
5. 按 `Cmd + S` 儲存

✅ 確認：上方沒有紅色錯誤，函式下拉選單（「執行」按鈕旁邊）可以選到 `setup`

---

## 步驟 3：執行 setup（自動建立所有分頁）

1. 函式下拉選 **setup** → 按 **▶ 執行**
2. 跳出「需要授權」→ **審查權限** → 選你的 Google 帳號
3. 出現「Google 尚未驗證這個應用程式」→ 點左下 **進階** → **前往「OrderEat」（不安全）**
   - 這是你自己寫的程式，所以 Google 沒審核過，可以放心
4. 權限清單（試算表、雲端硬碟）→ **允許**
   - 雲端硬碟權限用來存菜單照片
5. 等下方「執行記錄」出現 `設定完成。API Token：xxxxxxxx`
6. **把這串 Token 複製起來**（步驟 7 要用）

✅ 確認：回到試算表分頁，下方出現 8 個分頁：
`餐廳`、`品項`、`客製選項`、`成員`、`每日記錄`、`點餐明細`、`今日彙總`、`統計`

> 原本的「工作表1」可以按右鍵刪除。
> 重新整理試算表後，上方會多一個 **OrderEat** 選單，隨時可以「顯示 API Token」。

---

## 步驟 4：部署成網頁應用程式

1. 回到 Apps Script 分頁，右上 **部署 → 新增部署作業**
2. 左邊齒輪 ⚙ → 選 **網頁應用程式**
3. 填寫：
   - 說明：`v1`
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按 **部署**（如果又要求授權，照步驟 3 做一次）
5. 複製 **網頁應用程式網址**，長這樣：
   `https://script.google.com/macros/s/AKfycb..../exec`

✅ 確認：手上有兩樣東西 — **網址** 和 **Token**

> 「所有人」是指拿得到網址的人都能呼叫，但每個請求都要帶正確的 Token 才能讀寫。網址和 Token 不要傳給別人。

---

## 步驟 5：用瀏覽器測試連線

瀏覽器網址列貼上（換成你的網址和 Token）：

```
https://script.google.com/macros/s/你的ID/exec?action=ping&token=你的Token
```

✅ 確認：畫面顯示 `{"ok":true,"data":{"pong":true,...}}`

故意把 Token 打錯一個字再試，應該看到 `{"ok":false,"error":"token 錯誤"}`。

## 步驟 6：輸入第一間店（範例：飲料店）

### 6-1 `餐廳` 分頁
| id | 店名 | 分類 | 電話 | 地址 | 備註 | 停用 |
|---|---|---|---|---|---|---|
| （自動） | 50嵐 | 飲料 | 02-1234-5678 | | | ☐ |
| （自動） | 八方雲集 | 便當, 麵 | | | 週日公休 | ☐ |

- **id 不用填**，輸入店名後會自動產生
- **分類**用逗號分隔，可多個；App 抽籤時按這個篩選
- **停用**打勾 = 不再出現在 App（不用刪資料）
- `菜單照片`、`照片檔ID` 欄由 App 上傳時自動填
- `Google地圖`（選填）：Google 地圖搜尋店家 →「分享」→「複製連結」貼上（`https://maps.app.goo.gl/...`）。空白也可以，App 會用「店名＋地址」搜尋
- `連結選單`（選填）：店家線上菜單或點餐網頁（例如 `https://shop.dsorder10.com/...`）。有填 App 才會出現「線上菜單」按鈕

### 6-2 `客製選項` 分頁
| id | 餐廳 | 選項名稱 | 類型 | 必選 | 選項內容 | 可選數量 |
|---|---|---|---|---|---|---|
| （自動） | （空白） | 甜度 | 單選 | ☑ | `正常\|少糖\|半糖\|微糖\|無糖` | |
| （自動） | （空白） | 冰塊 | 單選 | ☑ | `正常\|少冰\|微冰\|去冰\|熱` | |
| （自動） | 50嵐 | 加料 | 多選 | ☐ | `珍珠+10\|椰果+10\|布丁+15` | 3 |
| （自動） | （空白） | 尺寸 | 單選 | ☑ | `中杯\|大杯+10` | |
| （自動） | 金大富 | 雙寶配菜 | 多選 | ☑ | `燒腩\|烤鴨\|叉燒\|油雞\|雞腿` | 2 |

- **餐廳留空 = 通用**，所有店都能用（甜度、冰塊這種很常用）
- **餐廳選某間店 = 只有那間店用**；同名時店家專用的優先
- **選項內容**用 `|` 分隔；要加價寫 `+10`，折價寫 `-5`
- **類型**：單選（只能選一個）／多選（可選多個或不選）
- **必選**打勾 = 點餐時一定要選
- **可選數量**（只有多選用得到）：空白 = 不限；**必選＋2 = 剛好選 2 個**（例如雙寶五擇二）；不必選＋3 = 最多 3 個

### 6-3 `品項` 分頁
| id | 餐廳 | 品名 | 價格 | 客製選項 | 停用 |
|---|---|---|---|---|---|
| （自動） | 50嵐 | 珍珠奶茶 | 55 | 尺寸, 甜度, 冰塊, 加料 | ☐ |
| （自動） | 50嵐 | 四季春 | 35 | 尺寸, 甜度, 冰塊 | ☐ |
| （自動） | 八方雲集 | 招牌鍋貼 10 顆 | 65 | | ☐ |

- **餐廳**從下拉選單選（要先在 `餐廳` 分頁建好）
- **價格**填基本價；加價由客製選項處理
- **客製選項**填 `客製選項` 分頁的「選項名稱」，逗號分隔

### 6-4 `成員` 分頁
**不用填**，App 新增成員時會自動備份到這裡。

✅ 確認：瀏覽器開
```
https://script.google.com/macros/s/你的ID/exec?action=bootstrap&token=你的Token
```
看到 JSON 裡有 `restaurants`、`menuItems`、`optionGroups`，珍珠奶茶的 `optionGroupIds` 有 4 個 id。

## 步驟 7：把網址和 Token 填進 Android 專案

打開專案根目錄的 `local.properties`，最下面加兩行：

```properties
ORDEREAT_SCRIPT_URL=https://script.google.com/macros/s/你的ID/exec
ORDEREAT_TOKEN=你的Token
```

> `local.properties` 只存在你電腦，不會上傳 git，Token 不會外流。

✅ 確認：存檔完成。Sheet 端到這裡就設定好了。

## 步驟 8（選做）：模擬送出一筆訂單

Mac 終端機貼上（換掉網址、Token，**日期改成今天**）：

```bash
curl -L -H "Content-Type: application/json" \
  -d '{"token":"你的Token","action":"submitSession","payload":{"session":{"sessionId":"test-1","date":"2026-10-07","mealType":"午餐","restaurantId":"","restaurantName":"測試店","note":"測試"},"lines":[{"member":"小明","itemName":"珍珠奶茶","options":"大杯/半糖/少冰","qty":2,"unitPrice":65,"subtotal":130,"note":""},{"member":"小華","itemName":"四季春","options":"無糖/去冰","qty":1,"unitPrice":35,"subtotal":35,"note":"分開裝"}]}}' \
  "https://script.google.com/macros/s/你的ID/exec"
```

✅ 確認：
- 回應 `{"ok":true,"data":{"sessionId":"test-1","lineCount":2,"total":165,...}}`
- `每日記錄` 多一列、`點餐明細` 多兩列
- `今日彙總` 出現依品項、依人、明細三張表
- 在 `點餐明細` 勾小明的「已付款」，再執行一次同樣的 curl → 小明的勾還在

測完把 `每日記錄`、`點餐明細` 的測試列刪掉即可。

## 之後要知道的事

### 修改程式後要「更新部署」
改了 `Code.gs` 後，**一定要**：部署 → **管理部署作業** → 鉛筆 ✏ → 版本選 **新版本** → 部署。
網址不會變。**不要**按「新增部署作業」，那會產生新網址。

### 各分頁用途
| 分頁 | 誰維護 | 用途 |
|---|---|---|
| 餐廳／品項／客製選項 | 你在 Sheet 手動 | 菜單資料，App 同步下載 |
| 成員 | App 自動 | 成員名單備份 |
| 每日記錄 | App 自動 | 每團一列：哪天吃哪間、總額、備註 |
| 點餐明細 | App 自動，「已付款」你手動勾 | 每人每品項一列 |
| 今日彙總 | 公式 | 打電話給店家、收錢用 |
| 統計 | 公式 | 本月各店次數、每人花費、各店最後一次吃 |

### 手動放菜單照片（不用 App 拍）
1. 照片丟進雲端硬碟的 `OrderEat 菜單照片` 資料夾
2. 照片按右鍵 → 共用 → 一般存取權改「**知道連結的任何人**」→ 複製連結
3. 貼到 `餐廳` 分頁該店的 `菜單照片` 欄

### 常見問題
| 狀況 | 處理 |
|---|---|
| App 看不到某間店／品項 | 檢查「停用」沒打勾、品項的「餐廳」名稱跟 `餐廳` 分頁一致 |
| 客製選項沒出現 | 品項的「客製選項」名稱要跟 `客製選項` 分頁的「選項名稱」完全一樣 |
| `今日彙總` 顯示「今天還沒有訂單」 | 正常，今天還沒人送單；或日期不是今天 |
| 公式壞了 | 選單 **OrderEat → 重新建立彙總／統計公式** |
| 明細上方一堆空白列、資料跑到很下面 | 選單 **OrderEat → 整理空白列** |
| Token 外流 | 選單 **OrderEat → 重新產生 Token**，更新 `local.properties` 後重裝 App |
| 回應 `尚未執行 setup()` | 回步驟 3 再執行一次（不會清資料） |
| 改了程式沒生效 | 看上面「修改程式後要更新部署」 |
